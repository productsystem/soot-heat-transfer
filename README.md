# LII Model (Lemaire 2021)

This repository implements a laser-induced incandescence (LII) model based on the following paper:

## Reference
Lemaire, R., & Menanteau, S. (2021).  
Modeling laser-induced incandescence of Diesel soot.  
*Applied Physics B*, 127, 138.  
https://doi.org/10.1007/s00340-021-07665-y  

## Notes
- This code reproduces the published model equations.
- No unpublished experimental data (e.g., CERL data) is included.
- All parameters are sourced from the paper or cited references.
